# Torque Calculator PWA 🔧

A simple, offline-capable bolt torque calculator built as a Progressive Web App (PWA). Supports metric and imperial units.

## 💡 Features
- Metric and Imperial support
- Friction coefficient input
- PDF export of results
- Works offline (PWA)
- Installable on desktop & mobile

## 🛠 Deployment via GitHub Pages

1. **Create GitHub repo** and push the contents of this folder.
2. Go to **Settings > Pages**.
3. Under **"Source"**, choose:
   - Branch: `main` (or `master`)
   - Folder: `/ (root)`
4. Save. Your app will be live at:
   ```
   https://your-username.github.io/torque-calculator/
   ```

## 📲 Install as App
- On Chrome/Edge: Click "Install" from the address bar.
- On mobile: Add to Home Screen from browser menu.
